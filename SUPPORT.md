# Support

Use [GitHub Issues](https://github.com/lxdb/bsbctl/issues) for reproducible defects, documentation errors, and focused feature requests.

Include the bsbctl version or commit, macOS version, BUSY Bar firmware version when relevant, affected daemon or plugin operation, exact error, and the smallest safe reproduction. Remove credentials, device identifiers, calendar details, Codex session content, and other personal data.

This project does not provide emergency or guaranteed support. Follow [SECURITY.md](SECURITY.md) for confidential vulnerability reports; do not post undisclosed vulnerability details in an issue.
