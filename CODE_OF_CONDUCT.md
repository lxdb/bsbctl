# Code of conduct

## Expected behavior

Treat other participants with respect. Give technical feedback about the work, not the person. Ask for evidence and respect privacy.

## Unacceptable behavior

Harassment, discrimination, threats, sustained disruption, publication of another person's private information, sexualized language, and unwanted attention are not acceptable.

## Enforcement

Report conduct concerns privately through the repository owner profile. Do not include secrets or unrelated personal data in a report.

Maintainers can edit, reject, or remove contributions that violate this policy and can temporarily or permanently restrict participation.
